# THE LILYWHITES LEGACY

토트넘 시즌 드래프트 비영리 팬게임입니다. 
팬들이 무료로 즐길 수 있도록 운영하며 광고를 게재하지 않습니다.

[게임 플레이](https://woong14.github.io/the-lilywhites-38/)

## 게임 소개

시즌 룰렛으로 선수를 선발해 11명의 스쿼드를 구성하고, 팀 케미를 조합해 리그 38경기와 토너먼트를 진행하는 팬게임입니다. 
프로필에서 시즌 기록, 카드 도감, 팀 케미와 도전과제를 확인할 수 있습니다.

## 이용 조건

- 제작자의 별도 허락 없는 상업적 이용 및 게임 파일의 재배포를 허용하지 않습니다.
- 게임 파일을 복사하거나 수정해 다른 사이트에 게시·배포하는 경우도 재배포에 포함됩니다.
- 지인에게 게임 링크를 전달하거나 카페·커뮤니티·SNS 등에 공유하는 것은 허용합니다. 게임 파일 재배포와 링크 공유는 구분됩니다.
- 다만 게임과 이용자를 조롱·비방하거나 분쟁을 유도할 목적으로 공유하는 행위는 금합니다.
- 공개 저장소의 열람·포크에는 GitHub 이용약관이 적용됩니다. 위 안내는 상업적 이용이나 외부 재배포를 별도로 허락한다는 뜻이 아닙니다.
- 제3자 자료에는 해당 권리자의 이용 조건이 적용됩니다. 이 안내로 제3자 자료의 이용 권한을 부여하지 않습니다.

## 이용자 운영 기준

본 게임의 능력치는 팬게임을 위한 임의 설정입니다. 
의견과 개선 제안은 환영하지만, 구단·선수·이용자를 향한 욕설이나 도발성 닉네임, 반복적인 괴롭힘은 운영자가 변경 요청 또는 이용 제한할 수 있습니다.

## 팬게임 안내

본 게임은 토트넘 홋스퍼 또는 선수들과 공식적으로 제휴하거나 승인받은 게임이 아닙니다. 
제3자 상표·이미지 등의 권리는 각 권리자에게 있습니다.

선수 OVR과 게임 내 설정은 팬게임을 위한 임의의 수치·연출이며 공식 평가가 아닙니다.
